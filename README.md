# Sky Plane Battle

Python + Pygame 飞机大战 / Sky Shooter

一个面向少儿编程与 Python 初学者的 Pygame 项目实践。

项目通过**5个逐步迭代的版本**，搭配**丰富的注释TODO引导**学习者从玩家移动和基础游戏循环开始，逐渐完成敌机生成、自动射击、碰撞计分、游戏状态、滚动背景、音乐音效和爆炸动画，最终形成一款完整的飞机大战小游戏。


## 游戏介绍

玩家可以使用方向键或 `W/A/S/D` 控制飞机移动。飞机会自动发射子弹，击毁敌机后获得分数；如果玩家飞机与敌机发生碰撞，游戏结束，并可按任意键重新开始。

在基础战斗玩法之外，游戏还包含中英文界面、精确碰撞检测、连续滚动背景、不同状态下的背景音乐、战斗音效和序列帧爆炸特效。
## 版本概览

项目按照功能逐步迭代为 5 个版本。每个版本都建立在前一版本的基础上，并通过代码中的 `TODO` 引导学生完成本阶段最关键的功能。

1. 对应 `game1/`
   - 建立 Pygame 窗口和基础游戏循环。
   - 实现玩家飞机的键盘控制、位置更新、画面绘制和边界限制。
   - 理解事件处理、状态更新和画面刷新组成的基本运行流程。

2. 对应 `game2/`
   - 在玩家移动的基础上加入敌机。
   - 实现敌机从屏幕上方随机生成并持续向下移动。
   - 学习使用列表管理多个敌机，并及时清理已经离开屏幕的对象。

3. 对应 `game3/`
   - 加入自动射击功能和基础战斗循环。
   - 实现子弹的创建、移动、绘制和越界清理。
   - 完成子弹与敌机的碰撞处理，理解不同游戏对象之间如何协作。

4. 对应 `game4/`
   - 加入分数统计和像素级精确碰撞检测。
   - 完成开始、游戏中、游戏结束和重新开始的状态流程。
   - 实现中英文界面切换，使游戏具备完整的基础玩法和交互界面。

5. 对应 `game5/`
   - 添加游戏背景并实现连续滚动效果。
   - 根据游戏状态播放和切换背景音乐，加入敌机爆炸与玩家坠毁音效。
   - 使用多张连续图片实现爆炸动画，并处理动画的创建、更新、绘制和自动清理。

各版本使用相近的文件结构和命名方式，方便学生对照前后代码变化。建议按照 `game1` 到 `game5` 的顺序完成 TODO，并在每个阶段运行游戏、检查效果后再进入下一版本。

## 运行项目

运行前需要安装 Python 和 Pygame：

```bash
pip install pygame
```

在项目根目录中选择对应版本运行，例如：

```bash
python game1/main.py
```

请从项目根目录启动游戏，以确保 `assets/` 中的图片和音频资源能够正常加载。

# Sky-Plane-Battle
python pygame planer war, Sky Shooter

少儿编程演示项目

### 思路梳理 - 版本1 基础
#### 1 实现飞机移动
`game1.py` - 飞机基础移动功能

**实现内容：**
- 使用 pygame 加载飞机图片 `assets/player1.png`
- 支持 WASD/方向键 四个方向移动
- 使用 dt (delta time) 实现平滑帧率无关的移动
- 边界检测：飞机不超出屏幕范围
- 屏幕尺寸：500×800 像素，移动速度 300 像素/秒

#### 2 添加敌人
game2.py 添加敌人 Enemy class
使用图片 `assets/enemy1.png`
敌人从顶部随机生成，不断往下移动。超出界面则清理掉。
先不用做碰撞检测，也不用子弹。

#### 3 添加射击功能 动画
game3.py 添加Player 发射子弹, 从中间顶部那个头那里射出子弹，以及碰撞敌人逻辑，子弹击中敌人，敌人和子弹就会都消失掉。
子弹超出上界也会被清理掉。
子弹素材使用bullet1.png


#### 4 被撞击，被攻击处理
game4.py
添加开始界面，提示玩家按任意键开始游戏
添加分数功能，每清理一个低级敌人得分10分。
实现碰撞死亡功能
如果玩家飞机被敌人撞到，直接死亡。
死亡后展示玩家分数，并提示按任意键重新开始游戏

优化碰撞逻辑，最好是飞机主体和敌人主体碰到了再算是碰撞死亡，而不是整个图片所处在的大的矩形。

#### 5 梳理拆分与优化
将game4.py 里面的代码梳理拆解到不同的文件，放在game1文件夹下，
同时展示的文字，做出中英文两个版本，可以切换中英文。
